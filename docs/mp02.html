load_atus_data <- function(file_base = c("resp", "rost", "act")) {
    
    if (!dir.exists(file.path("data", "mp02"))) {
        dir.create(file.path("data", "mp02"), showWarnings = FALSE, recursive = TRUE)
    }

    file_base <- match.arg(file_base)

    file_name_out <- file.path(
        "data", "mp02",
        glue("atus{file_base}_0324.dat")
    )

    if (!file.exists(file_name_out)) {
        url_end <- glue("atus{file_base}-0324.zip")
        temp_zip <- tempfile(fileext = ".zip")
        temp_dir <- tools::file_path_sans_ext(temp_zip)

        request("https://www.bls.gov") |>
            req_url_path("tus", "datafiles", url_end) |>
            req_headers(`User-Agent` = "Mozilla/5.0") |>
            req_perform(path = temp_zip)

        unzip(temp_zip, exdir = temp_dir)

        temp_file <- file.path(temp_dir, basename(file_name_out))
        file.copy(temp_file, file_name_out, overwrite = TRUE)
    }

    file <- read_csv(file_name_out, show_col_types = FALSE)

    result <- switch(
        file_base,

        resp = file |>
            mutate(
                children_under_18 = TRCHILDNUM,
                employment_status = case_match(
                    TELFS,
                    1 ~ "Employed - at work",
                    2 ~ "Employed - absent",
                    3 ~ "Unemployed - on layoff",
                    4 ~ "Unemployed - looking",
                    5 ~ "Not in labor force",
                    .default = "Other"
                )
            ) |>
            rename(
                survey_weight = TUFNWGTP,
                time_alone = TRTALONE,
                survey_year = TUYEAR
            ),

        rost = file,

        act = file |>
            mutate(
                time_spent_min = TUACTDUR24,
                level3_code = TRCODEP
            )
    )

    result |>
        rename(participant_id = TUCASEID)
}

The respondent dataset contains demographic and survey-level information for each participant, including variables such as survey year and survey weight. The activity dataset contains detailed time-use records, where each row represents one activity completed by a participant along with its duration and activity code. The activity labels dataset provides readable names for activity codes.

Based on the structure of these datasets, the main key used to connect them is participant_id. The activity dataset can also be joined with the activity labels dataset using activity codes to translate numeric values into meaningful activity names.

Task 7: Time Use Categories for Target Demographics

Stay-at-Home Dads

The first target demographic is stay-at-home fathers. This group is defined as adult men who are not in the labor force and have at least one child under the age of 18 in the household. These individuals are likely responsible for childcare and household responsibilities.

Key activities for this group include childcare, household work, and personal time such as sleep. Based on the data, childcare and household activities take up a significant portion of their day.

Typical time use levels:

  • Childcare: Low = 1 hour, Medium = 3 hours, High = 6 hours
  • Household activities: Low = 1 hour, Medium = 2.5 hours, High = 5 hours
  • Sleep: Low = 5 hours, Medium = 7 hours, High = 9 hours

College Undergraduates

The second demographic is college undergraduate students. This group is defined as individuals who are currently enrolled in college-level education programs and are typically between ages 18 and 24.

Key activities include studying, attending class, sleeping, and leisure activities. While students spend time on education, there is also a significant amount of time allocated to personal and recreational activities.

Typical time use levels:

  • Studying: Low = 1 hour, Medium = 3 hours, High = 6 hours
  • Sleep: Low = 5 hours, Medium = 7 hours, High = 9 hours
  • Leisure: Low = 2 hours, Medium = 4 hours, High = 7 hours

Young Working Professionals

The final demographic is young working professionals. This group is defined as individuals between the ages of 22 and 30 who are employed full-time and not currently enrolled in school.

Key activities include work, exercise, sleep, and leisure. This group often balances career development with personal well-being.

Typical time use levels:

  • Work: Low = 6 hours, Medium = 8 hours, High = 10+ hours
  • Exercise: Low = 0.5 hours, Medium = 1 hour, High = 2 hours
  • Sleep: Low = 5 hours, Medium = 7 hours, High = 8+ hours
