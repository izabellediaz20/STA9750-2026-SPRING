Introduction

In 2023, the U.S. Supreme Court ruled in Students for Fair Admissions v. Harvard (SFFA) that race-conscious admissions policies violated the Equal Protection Clause of the Fourteenth Amendment. This decision significantly changed how universities approach admissions and raised questions about how the ruling might affect student diversity across institutions.

This project analyzes admissions and enrollment data from the Integrated Postsecondary Education Data System (IPEDS), maintained by the U.S. Department of Education. The dataset provides detailed information on college enrollment, including demographic characteristics of students across institutions.

Using data analysis tools in R, this report examines enrollment patterns and demographic trends in higher education institutions before and after the SFFA decision. The goal is to explore whether the removal of race-conscious admissions policies has had any observable impact on the composition of student populations at universities across the United States.

Data Acquisition

The following code downloads enrollment and institutional data from the Integrated Postsecondary Education Data System (IPEDS). To make the process efficient, the data are saved locally in the data/mp01 folder so the files do not need to be downloaded again if the analysis is rerun.

# Acquire IPEDS Data for MP#01

acquire_ipeds_data <- function(start_year=2010, end_year=2024){
    library(tidyverse)
    library(glue)
    
    data_dir <- file.path("data", "mp01")
    
    if(!dir.exists(data_dir)){
        dir.create(data_dir, showWarnings=FALSE, recursive=TRUE)
    }
    
    YEARS <- seq(start_year, end_year)
    
    EFA_ALL <- map(YEARS, function(yy){
        if(yy <= 2022){
            ef_url <- glue("https://nces.ed.gov/ipeds/datacenter/data/EF{yy}A.zip")
        } else {
            ef_url <- glue("https://nces.ed.gov/ipeds/data-generator?year={yy}&tableName=EF{yy}A&HasRV=0&type=csv")
        }
        
        ef_file <- file.path(data_dir, glue("ef{yy}a.csv.zip"))
        
        if(!file.exists(ef_file)){
            message(glue("Downloading Enrollment Data for {yy} from {ef_url}"))
            download.file(ef_url, destfile = ef_file, quiet=TRUE, mode="wb")    
        }
        
        read_csv(ef_file, show_col_types=FALSE) |>
            mutate(
                year = yy,
                enrollment_m_aian = EFAIANM,
                enrollment_f_aian = EFAIANW,
                enrollment_m_asia = EFASIAM,
                enrollment_f_asia = EFASIAW,
                enrollment_m_bkaa = EFBKAAM,
                enrollment_f_bkaa = EFBKAAW,
                enrollment_m_hisp = EFHISPM,
                enrollment_f_hisp = EFHISPW,
                enrollment_m_nhpi = EFNHPIM,
                enrollment_f_nhpi = EFNHPIW,
                enrollment_m_whit = EFWHITM,
                enrollment_f_whit = EFWHITW,
                enrollment_m_2mor = EF2MORM,
                enrollment_f_2mor = EF2MORW,
                enrollment_m_unkn = EFUNKNM,
                enrollment_f_unkn = EFUNKNW,
                enrollment_m_nral = EFNRALM,
                enrollment_f_nral = EFNRALW
            ) |>
            filter(
                (EFALEVEL %in% c(2, 12)) | (LINE %in% c(1, 15))
            ) |>
            mutate(
                level = case_when(
                    EFALEVEL == 2 ~ "all undergrad",
                    EFALEVEL == 12 ~ "all graduate",
                    LINE %in% c(1, 15) ~ "first year undergrad"
                )
            ) |>
            select(
                institution_id = UNITID,
                year,
                level,
                starts_with("enrollment_")
            ) |>
            group_by(institution_id, year, level) |>
            summarize(across(starts_with("enrollment_"), sum), .groups = "drop")
        
    }) |> bind_rows()
    
    DESC_ALL <- map(YEARS, function(yy){
        if(yy <= 2022){
            hd_url <- glue("https://nces.ed.gov/ipeds/datacenter/data/HD{yy}.zip")
        } else {
            hd_url <- glue("https://nces.ed.gov/ipeds/data-generator?year={yy}&tableName=HD{yy}&HasRV=0&type=csv")
        }
        
        hd_file <- file.path(data_dir, glue("hd{yy}.csv.zip"))
        
        if(!file.exists(hd_file)){
            message(glue("Downloading Institutional Descriptions for {yy} from {hd_url}"))
            download.file(hd_url, destfile = hd_file, quiet=TRUE, mode="wb")    
        }
        
        suppressWarnings(
            read_csv(
                hd_file,
                show_col_types=FALSE,
                locale=locale(encoding=if_else(yy == 2024, "utf-8", "windows-1252"))
            ) |>
            mutate(year = yy) |>
            select(
                institution_id = UNITID,
                institution_name = INSTNM,
                state = STABBR,
                year
            )
        )
        
    }) |> bind_rows()
    
    inner_join(
        EFA_ALL,
        DESC_ALL,
        by = c("institution_id", "year")
    )
}

As president of Baruch College, I believe that diversity is fundamental to the educational mission of our institution. Diversity strengthens our classrooms, broadens our perspectives, and prepares our students to thrive in an increasingly interconnected world. This definition reflects the historical disparities that have shaped access to higher education in the United States.

Baruch College currently serves a large and vibrant undergraduate community. In 2024 the college enrolled approximately 16,496 undergraduate students. These students represent a wide range of backgrounds, cultures, and life experiences, contributing to a dynamic learning environment that prepares graduates for leadership in New York City and beyond.

While year-to-year changes are often small, the long-term trend illustrates the evolving composition of our student body.

By continuing to evaluate our data and reflect on our mission, we can ensure that our campus remains a place where all students are empowered to learn, lead, and contribute to our diverse society.
